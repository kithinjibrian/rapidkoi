# Icons

Icons copied from [Iconsax](https://iconsax.io) for Rapidkoi's own UI (the frame: account, menu, and later the rest).

- Keep each icon's Iconsax name, and note its style (linear, bold, outline…) in the name if more than one is used: `user.svg`, `menu-bold.svg`.
- Check Iconsax's licence covers shipping them in Rapidkoi before release, and keep a copy of it here.
- kivuli 0.18 shows PNG and JPEG pictures and theme icons only, not SVG files. Using these in the window needs a decision first (DECISIONS.md): SVG support in kivuli, PNG exports, or an icon theme folder.
