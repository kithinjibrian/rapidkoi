# Lugha request: embed a file's bytes at compile time

From Rapidkoi, session 157 (DECISION-038). For a Lugha session in `../lugha`, under Lugha's own CLAUDE.md and milestone process. Rapidkoi never builds or installs `lughac` itself; the owner does.

## What Rapidkoi needs

Rapidkoi ships apps of its own, starting with the new tab: a Rust app built with cargo and packed into a signed bundle (`newtab.rkb`, tens of kilobytes). The owner chose to ship it **inside the `./main` binary**, so Rapidkoi is one file that can't come apart from its own new tab. Today the only way is to paste the bytes into a source file as a list literal: thousands of lines, regenerated by hand, against Rapidkoi's 500-line file limit. Rapidkoi already does a small version of this for its icons (`src/ui/icons.la` holds each SVG as a string, a test keeping them equal to `assets/icons/`).

## What to add

A compile-time built-in that reads a file and gives its contents as a constant, like Rust's `include_bytes!` and `include_str!`, Zig's `@embedFile`, Go's `//go:embed`:

```
const NEWTAB: u8[] = include_bytes("../apps/newtab.rkb");
const LOGO: string = include_str("../assets/icons/home.svg");
```

Suggested rules (Lugha's to decide):
- **Paths are relative to the source file** that names them, with `/`, not empty.
- **Stays inside the package:** no `..` beyond the package's folder (as a manifest's `source` can't leave it, section 6), no absolute paths, no symlinks followed out. So a package can't read the builder's other files.
- **A constant expression** (section 2's `const`): usable in `const`, evaluated once at compile time, the bytes placed in the binary's read-only data.
- **Errors at compile time:** a missing file, one outside the package, or one over a size cap (say 16 MB) is an error with its own code, at the call. `include_str` on bytes that aren't UTF-8 is an error too.
- **Rebuilds:** a changed file rebuilds what includes it (lughac's caching, if any, keys on the file's contents).
- **Tooling:** `lughac fmt` leaves it alone; the language server can show the file's size on hover.

## Notes for Lugha

- `lughac` reads only a package's `.la` files and `lugha.toml` today (section 6, "What runs"); this adds files a package names explicitly, read, never run.
- Git packages: the file comes with the package's checkout like its sources.
- Generic: any Lugha program shipping data (icons, fonts, default config, test fixtures) wants it.

## What Rapidkoi does until then

Builds the new-tab app and its signed bundle (the Rust app, the packing and signing step, the build script), and doesn't run it inside Rapidkoi until `include_bytes` lands; empty tabs stay empty meanwhile. Then the icons move to `include_str` too.
