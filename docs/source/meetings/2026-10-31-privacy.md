# Privacy — design in chat, 2026-10-31

From the users talk, the owner asked how Rapidkoi avoids fingerprinting, then built on it: time zones narrow down location, so apps should ask Rapidkoi to show time for them. Recorded as core decision 30 and its amendments, DECISION-079 and 080.

## Fingerprinting — settled (core decision 30)

An app or its server recognising a person without asking, across apps, after Start over, or over time, by combining small signals.

- **Already strong:** Rapidkoi draws, apps describe, so apps never measure fonts, screens or pixels (most web fingerprinting); per-app keys; pictures fetched with no headers or cookies; declared servers only; three preferences.
- **Leaks found:** the IP address (requests through the Pond deferred, DECISION-080); text size 80–200; Start over kept the app's database, so a stored id recognised the person again (now cleared, the owner: "start over clears the database", DECISION-079, not built); request headers (what `std.http` adds by default: to check); timing, once apps get time; ids an app puts in links.
- **Six rules:** no measurements; values from short shared lists; the same requests from every Rapidkoi; a "what it reveals" section in each capability's PRP; the inspector shows reads and contacts; Start over is a new person.

## The show pattern — settled (amendment)

The owner's idea: `text("time: {to_local_time(utc_time)}")` that only Rapidkoi can run. Rapidkoi already does it for the name (placeholders). Refined into data, not code: a time node drawn in the person's zone; a picker answering UTC; a time zone permission only for local day logic (calendars).

The owner widened it: "think of the places where apps require a person info to customize something". Five patterns: show (Rapidkoi fills the value in), adapt (Rapidkoi adjusts the screen from the app's rules), ask (a permission when a server needs it), hand over (the person's own act), never. A table maps name, time, language, numbers and units, week start, look, screen reader, width, location, contacts, forms and region.

## In code

Asked to "show me in code": a text becomes parts (`["Edited ", { "time": 1730370000, "show": "relative" }]`); the app writes `text(["Edited ", time(note.updated).relative()])`; Rapidkoi fills the parts into words between decoding and drawing (the same place as `src/guest/placeholders.la`), never into typing boxes or titles, and keeps "relative" current itself. Asked how `{FIRST_NAME}` would be replaced: by a name part; nothing outside the shell uses the tokens, so they go outright, best in the contract that brings time (DECISION-083).

## No interpreter — settled (amendment)

The owner asked why a small interpreter was ruled out. Any decision on a person's value can be steered out: a button only in one branch tells the app which branch ran; a picture's address built from it tells a server. The rule: anything worked out from the person's values only ever becomes text on screen. A text-only formatting language (ICU MessageFormat's plurals) keeps the rule and is allowed, likely with translations.
